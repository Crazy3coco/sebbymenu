# 🎩 집사 세바스찬의 만찬 (모바일 HTML 게임)

외부 라이브러리·빌드 과정 없이 `index.html` 하나로 동작합니다.

## VSCode에서 실행
1. VSCode로 이 폴더를 엽니다 (`파일 > 폴더 열기`).
2. 확장 프로그램 **Live Server** (ritwickdey.LiveServer) 설치.
3. `index.html` 우클릭 → **Open with Live Server**.
4. 브라우저에서 `F12` → 기기 툴바(Ctrl+Shift+M)로 모바일 화면 확인.

### 실제 휴대폰으로 테스트
- PC와 폰을 같은 Wi-Fi에 연결 후, 폰 브라우저에서 `http://<PC의 IP>:5500` 접속.
- Live Server가 안 되면: 터미널에서 `npx serve .` (또는 `python -m http.server 5500`).
- 접속이 막히면 PC 방화벽에서 5500 포트를 허용하세요.

## 조작법
1. 아래 메뉴에서 **음식을 탭**(선택 표시) → 2. **손님을 탭**해서 서빙.
- 10초 안에 못 주면 손님이 화내며 떠나고 ❤️ -1 (하트 3개 모두 잃으면 종료).
- 시엘: 한 번에 여러 음식 주문, 음식 하나 낼 때마다 인내심 10초로 회복. 전부 내면 풀코스 보너스.
- 드루이드(Lv.2부터): 5번 연타로 퇴치(+150). 방치하면 2.5초마다 다른 손님 인내심 -1초, 12초 넘으면 ❤️ -1.
- 싫어하는 음식을 내면 인내심 -2초 + 콤보 끊김.

## 난이도 조절
`index.html` 상단 `설정` 블록의 상수를 수정하세요.
`PATIENCE`, `MAX_LIVES`, `SEATS`, `DRUID_TAPS`, `DRUID_STAY`, `WRONG_PENALTY`
(NPC/음식 추가는 `FOODS`, `NPCS` 객체에 항목 추가).

## 문제 해결
- 소리가 안 남: 모바일은 첫 터치 이후에만 재생됩니다. 무음 모드도 확인하세요.
- 이모지가 네모로 보임: 기기 OS를 최신으로 업데이트하세요 (🧇🥟 등은 신형 OS 필요).
- 그 외 오류는 브라우저 콘솔(F12) 메시지를 GitHub Issues/Stack Overflow에서 검색해 해결하세요.
